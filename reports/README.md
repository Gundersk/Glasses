# Отчёты

- `reports/monthly/YYYY-MM.md` — ежемесячный отчёт до 25-го числа.
- `reports/final/` — итоговые отчёты и версии для защиты.
- Черновик и отправленная версия — разные файлы: `draft.md` и `sent.md` (или дата в имени).

## Структура месячного отчёта

1. **Статус этапа:** что должно быть по дорожной карте и что реально сделано.
2. **Результаты:** только измеренное, с командой/логом/ссылкой на эксперимент.
3. **Что не получилось:** честно, с причиной.
4. **Источники:** новые источники за месяц, с датами и лицензиями.
5. **Риски:** что может сорвать следующий этап.
6. **План на следующий месяц:** 3–5 пунктов.
7. **Вопросы ментору:** 1–3 конкретных вопроса.

## Правила

- Не заявлять результаты, которых нет.
- Не переносить чужие числа как свои.
- Указывать дату и версию для каждого артефакта.
- Не отправлять отчёт без проверки `reviewer`, если он содержит метрики или выводы.

# Эксперименты

Один эксперимент — одна папка: `experiments/YYYY-MM-DD-slug/`.

```
experiments/2026-11-10-first-asr/
  README.md        # протокол и результат
  config/          # конфиги, seed, версии
  logs/            # stdout/stderr, метрики
  results/         # таблицы, графики, аудио/видео
```

## Правила

- Не менять README после завершения, кроме дописывания статуса; результаты не переписывать задним числом.
- Всегда сохранять команду запуска и версию модели.
- Не хранить в git большие аудио/видео и веса.
- Отрицательный результат — тоже результат; фиксировать его честно.
- Синтетика не заменяет реальные диалоги.

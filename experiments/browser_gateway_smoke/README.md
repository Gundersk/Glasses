# Техническая проверка вспомогательного Chat2API

`closes: LG-2026-11-14-01`. Дата 14.11.2026.

## Гипотеза

Настроенный браузерный шлюз способен вернуть короткое сжатие без расхода
основной ChatGPT-подписки. Это гипотеза доступности интеграции, не ASR-эксперимент.

## Данные и конфигурация

Один вымышленный неперсональный русский фрагмент: источник сообщает число 7,
план — проверить два файла, измерение в вымышленном примере — 3 строки.
Два технических обращения: до и после сопоставления alias→wire ID;
содержание проекта/ключи не передавались как входной текст. Seed не применим.
Windows, рабочая .venv; browser-session, endpoint loopback8080/v1,
модель alias deepseek-flash; второй wire ID deepseek-v4-flash.
Платный fallback выключен; обычная пауза/общий cooldown соблюдаются адаптером.
Настоящая квота площадки/число аккаунтов/версия upstream неизвестны.

## Команды и метрики

`python -m autonomy.assist digest --text <вымышленный фрагмент> --execute --browser-only --budget-usd 0`

Второй вызов: `assist.run('digest', text, budget=0, browser_only=True, wait_seconds=60)`.
Метрики технические: получение ответа, схема, сохранность чисел/статусов;
никаких WER/DER/сквозной задержки субтитров. Отдельно один авторизованный
GET `/v1/models` без генерации; сохранялись только HTTP-статус и ID.

## Получено

- GET каталога: HTTP200, 23 объявленных ID, не доказанная работоспособность.
- Оба обращения за сжатием: blocked, принятого модельного текста нет.
- Второй адаптер вернул безопасный `http_error`; точный HTTP-код/тело прежней
  ошибки не сохранены. Причина не установлена. После этого добавлена безопасная
  диагностика численного HTTP-кода для будущих обращений; повтор не запускался.
- Scout/нативный поиск не запускались. Экономия квоты и качество не измерены.
- Fallback проверен оффлайн с моками, реальный платный fallback здесь не запускался.

Артефакты: `docs/audits/2026-11-14/chat2api-{catalog,digest-smoke,tests}.json`,
`chat2api-review.md`. Общий протокол: 235 unittest и 23 standalone-проверки PASS.

## Ограничения и следующий шаг

Повтор после настройки владельца: один digest HTTP500, 17.734 с; scout не
запускался. Артефакт `chat2api-after-owner-setup-20261114T185523.json`: кириллица
в отправленном входе отсутствует, 183 знака `?` из-за PowerShell stdin. Это
ошибка нашего тестового транспорта, не свидетельство качества русскоязычной
модели. Не доказано, что она вызвала HTTP500. Исправленная воспроизводимая
заготовка — `python autonomy/tests/smoke_browser_aux.py`, по умолчанию без сети;
`--execute` здесь не выполнялся. Новая генерация — только после решения о повторе.

Не подменять technical blocked успешной эксплуатацией. Нужна безопасная
диагностика сервиса/аккаунта по панели или его логам; без циклических повторов,
сброса cooldown, обхода CAPTCHA и ротации аккаунтов. Затем один новый отдельно
ограниченный smoke, после успешного ответа — калибровка на фиксированных задачах.

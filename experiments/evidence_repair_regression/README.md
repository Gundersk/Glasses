# Регрессионная проверка диагностики и ремонта доказательств

Дата 14.11.2026. `closes: LG-2026-11-14-02`.

## Гипотеза

Структурированная диагностика всех плохих claims и ограниченный авторский пакет
позволяют исправить две независимые ошибки за одну разрешённую повторную попытку
в управляемом оффлайн-сценарии без нового поиска/ослабления проверки.

## Данные и конфигурация

Временные синтетические source JSON и mocked author/reviewer. Первая авторская
попытка содержит неверную цитату и отсутствующий URL, вторая корректна. Источники
имеют страницы с нужным текстом за пределами24000 символов. Дополнительно30 ошибок,
пакет REVIEW>60k, malformed prior, quotes через prefix, invalid paths/card binding.
Seed не применим: входы и ответы детерминированы. Windows, рабочая .venv,
код/тесты привязаны SHA256 в протоколе. Реальные сети/модели здесь не вызываются.

## Команды и критерии

`python -m unittest discover -s autonomy/tests -p 'test_*.py' -v`
и четыре standalone-скрипта из `evidence-repair-tests.json`.
Критерии: все адресные ошибки доступны следующему автору без3000-char clipping;
плохой ответ не вызывает semantic LLM; источники не повторяются; две попытки,
один сбор, один финальный смысловой REVIEW; пакет<=60k и видимые фрагменты точны.

## Получено

281 unittest и23 отдельные проверки PASS. В сквозном mocked-сценарии роли:
critic, collection verifier, author, author repair, final verifier; один shell-сбор.
Это проверка переходов/данных, не качества настоящей модели.

Дополнительная read-only проверка реального сохранённого v5 без run: C02 quote_missing,
C03 url_missing_in_evidence за один проход; пакет всех12 страниц59999 символов;
хеши82 исходных файлов совпали до/после. Старый v5 не принят и не переписан.

Артефакты: `docs/audits/2026-11-14/evidence-repair-tests.json`,
`evidence-repair-v5-readonly.json`, `evidence-repair-review.md`. ADR-0010.

## Ограничения

Фрагмент/цитата не доказывает вывод, выбор excerpts эвристический. Не подтверждены
качество живого repair, завершение поручения или экономия квоты. Семантические
проблемы C01/C05/C06/C08 в старом v5 не исправлялись. Новый обзор, поиск, ночь,
ручная редакция и отправка не запускались.

# Сохранение рабочего контекста

`closes: LG-2026-11-15-02`. 15.11.2026. ADR-0013.

## Основная сессия OpenCode

Внешняя компактизация остаётся auto/summary, keep24k, buffer20%, без background
и warming. Это настройки проекта; качество сводки не измерялось, модель-компактор
не заменялась. Дешёвое резюме не должно быть единственным источником договорённостей.

Перед длинной сессией/компактизацией: `/checkpoint`. Команда не запускает модели,
поиск, ночь или тесты; текущая сессия фиксирует краткую проверяемую записку:
цель/closes, последнее разрешение/запреты, решения, доказательства, ограничения,
блокеры/фоновые ID, следующий шаг. При этом нельзя выдумывать успешные прогоны.

После восстановления: читать `docs/session-handoff.md`, сверять SHA его первичных
источников. Несовпадение означает перечитать актуальные STATUS/agent-context/
протоколы. Handoff — подсказка, не разрешение и не замена PDF/scope/вердиктам.
`docs/session-handoff.sources.json` — snapshot хешей, не автоматически обновляемый
реестр. Отсутствующий/устаревший checkpoint не препятствует чтению первичных файлов.

Автоматическое включение handoff в стандартный compaction prompt OpenCode не
обещается. Команда ручная; инструкции восстановления описаны в agent-context.

## Внутренний оркестратор

- Отдельные вызовы ролей не наследуют чат-историю. Handoff строится из STATE/
  карточки/полной текущей задачи. Он сохраняет blocked/partial и не разрешает
  дополнительные действия. Прежние лимиты в machine contract остаются.
- В `WORKSPACE/context/` перед вызовом planner/executor/verifier сохраняется
  JSON manifest: размеры и хеш реального messages-пакета, исходные пути/SHA,
  included/omitted/selection mode, handoff. Prompt body не копируется.
- Критические документы/подписанная карточка/контекст и обязательные REVIEW
  response/claims/decision читаются целиком либо вызов блокируется. Файловые
  пределы —24k/160k/60k для трёх outputs, общий cap220k символов.
- STATUS: актуальная ведущая часть целиком, история после первого раздела
  «Предыдущее/Истор...» исключена явно. Не помещайте новые текущие ограничения
  ниже исторического раздела. Более16k актуального блока требует редакции,
  а не молчаливого усечения. Полная agent-context допускается до16k, scope до30k.
- Optional PROJECT/benchmarks/вспомогательные inputs могут быть сокращены;
  manifest это показывает. Наличие path не означает передачи всего файла.
- Source excerpts имеют собственный page-aware packet/URL/SHA/omissions,
  quote REVIEW — пакет всех цитат. Показанная выдержка не доказывает весь claim.
- Author attempt фиксируется после успешного prepare/manifest, но до вызова.
  Ошибка записи и переполнение не расходуют попытку. Команды без LLM не создают
  фиктивный manifest. Смысловой REVIEW/receipt и запрещённые пути сохраняются.

Параметры в autonomy/config.yaml: context_audit_enabled=true,
context_max_chars=220000. Они входят в approval hash; не отключать ради
«починить run». Диагностика контекста не равна billed/tokenizer limits.

## Проверки и оставшиеся риски

`context-preservation-tests.json`: граничные required JSON/diff, добавление
handoff, файловые отказы, секретные пути, STATE roundtrip, отсутствие fake
model call и записи после вызова; общий набор тестов и две scoped review.
Symlink-тесты могут быть пропущены без соответствующих Windows-прав — это
отдельная непроверенная ветка окружения, не PASS её сетевой безопасности.

Текущий packet hash — локальная проверяемость переданного текста, не гарантия
смысловой памяти модели. Увеличение keep или изменение модели-компактора
потребует отдельной одинаковой тестовой выборки/бюджета. Новых генераций здесь нет.

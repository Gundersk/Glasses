# ADR-0009: браузерный шлюз только для ограниченных вспомогательных ролей

14.11.2026. `closes: LG-2026-11-14-01`.
Статус: реализация по запросу владельца; готовность определяется протоколом
тестов/ревью в STATUS, не этим заголовком. Обязательства карты не меняются.

## Решение

Использовать существующий loopback Chat2API через отдельный browser-session
адаптер, не глобальным назначением агентам. Два маршрута: context_digest
(DeepSeek Flash) и source_scout (Perplexity), с явным выбором других allowlisted
моделей. Главные роли и независимые ворота остаются прежними.

Общий persistent SQLite ledger вне изолированного STATE карточек: квоты по
моделям и по группе, UTC-день, atomic reservation, single-flight и cooldown.
Round Robin upstream не трактуется как разрешение обходить ограничения аккаунта:
challenge/auth блокируют весь шлюз. Неизвестное завершение не даёт права на
следующий браузерный запрос. Никаких cookies, логинов и обхода CAPTCHA в клиенте.
Дневные caps панели неизвестны; локальные caps дополнительные, не замена им.
Ledger считает обращения клиента; внутренние retries/балансировку шлюза он
не видит. Их политика требует отдельной проверки и не считается настроенной.

Контекст — короткий контракт и выбранный неперсональный текст; output unverified.
Нет tools/команд/изменения статусов по ответу модели. Ссылки scout независимо
читаются и регистрируются как источники только после проверки. Hidden native
search не интегрируется в фиксированный research_policy карточек.

Fallback только существующий бюджетируемый Router (DeepSeek/Qwen API), без
нового платного OpenAI и без понижения требований critic/verifier. Явный
browser-only запрещает платный fallback. Нулевая оценка browser-cost не
означает бесплатный/безлимитный аккаунт и не доказывает экономию подписки.

## Альтернативы и цена

Назначить browser models всем агентам проще, но обходит центральные cooldown,
общую квоту и доказательную приёмку, зависит от непроверенного tools. Отвергнуто.
Использовать только штатные API надёжнее по контракту, но не использует новую
доступную ёмкость. Сохранено как fallback. Постоянные retries/ротация аккаунтов
после challenge отвергнуты. Пауза/ручной hold могут снизить доступность;
выигрыш цены и качество требуют отдельной калибровки, не обещаются по названию.

Документация/границы: `docs/browser-models.md`. Глобальный opencode.jsonc,
ROADMAP, старые карточки и разрешения ночи не меняются.

# ADR-0005. Сохранить оркестратор и сначала укрепить проверяемое исполнение

- Дата: 12.11.2026.
- closes: `LG-2026-11-12-01`.
- Статус: принято для ограниченного прототипа по запросу владельца на улучшение.
  Боевой цикл после изменений не проверен; карта и научные обязательства не меняются.

## Контекст

Нужны минимум ручного сопровождения, отчётность к 25-му, подготовка защиты,
экономия квоты и доказательства. В коде обнаружены обходы критика и приёмки;
само наличие нескольких ролей не давало требуемой надёжности.

## Решение

1. Не мигрировать сейчас и не возобновлять закрытый Argus-пилот.
2. Код управляет воротами, лимитами и фактами. Неодобренный план не выполняется.
3. Известные измерения — `execution: approved_commands`: точные команды из
   проверенного плана, без LLM-исполнителя. Сохранить командный протокол и логи.
4. Критик: существующий Kimi For Coding, затем отдельный платный кандидат
   `openai/gpt-6.1-sol` в пределах бюджета. Это **предварительное назначение**,
   не доказанный оптимум «цена/качество». Самопроверка автора запрещается по model ID.
   Kimi — максимум 8 физических попыток на весь прогон, платный резерв — 2.
5. Автоматическую свободную интерпретацию отчёта отключить: проверка чисел не
   выявляла ложных причин/выводов. Таблицы/ссылки/статусы собираются кодом.
6. Задачи могут завершаться автоматически; полное закрытие критерия этапа пока
   подтверждает владелец. Для автоматизации нужна полная исполнимая приёмка цели,
   а не произвольный существующий файл.

## Альтернативы и источники

| Вариант | Польза | Почему не переходить сейчас |
|---|---|---|
| Текущий Python-цикл | уже содержит цели, бюджет, приёмку, отчёт | исправляем конкретные дефекты; не объявляем полностью надёжным |
| LangGraph (S053) | persistence, interrupts, сохранение результатов узлов | не решает сам доказательность/методику; перенос и обслуживание не оценены |
| AI Scientist-v2 (S022) | идея→эксперимент→анализ | другой ML-сценарий и заявленная Linux/NVIDIA/CUDA среда; собственная ограничительная лицензия |
| Argus (S019) | роли и управляемые миссии | пилот закрыт владельцем; toy-успех на Pi не доказывает пригодность для научного проекта |

Заимствуем принципы checkpoint, идемпотентности и структурированных остановок,
не копируем код с иной лицензией. Независимость модели не гарантирует независимости
ошибок; это один из механизмов, а не замена проверкам.

## Цена и условия пересмотра

Платный резерв может быть дороже прежнего критика; проверять стоимость завершённой
принимаемой задачи, включая отказы и поиск. Локальный бюджет не гарантирует
абсолютный биллинг при сетевом обрыве/расхождении тарифов; внешний cap нужен отдельно.
После калибровки на фиксированных случаях заменить модели, если более дешёвый
кандидат не пропускает критические ошибки и имеет приемлемые ложные блокировки.
LangGraph рассматривать повторно лишь если наблюдаемые сбои восстановления не
удаётся устранить малым патчем, с оценкой стоимости переноса и контрольным тестом.

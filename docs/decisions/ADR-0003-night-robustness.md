# ADR-0003. Устойчивость автономной ночи: SSE-стриминг и границы песочницы

- **Дата:** 2026-11-09
- **Статус:** принято
- **Контекст:** система `autonomy/` проводила боевые ночи 2026-11-09. Три прогона подряд
  дали сбой не в логике моделей, а в инфраструктуре. Нужны были решения, которые
  фиксируют поведение системы надолго.

## Наблюдённые проблемы (измерено на нашей машине, `autonomy/workspace/runs/*.log`)

1. **Длинная генерация локальной модели обрывалась HTTP 502.** При `max_tokens` выше
   ~6K Strata gateway резал небуквальный POST примерно на 300 c (502). Короткие ответы
   (≤~6K токенов) проходили; задача `run-asr-*` с полным скриптом — нет. Повторных
   ретраев config запрещает (`retries: 0`), поэтому 502 означал провал исполнителя.
2. **Отличить «gateway жив» от «engine готов» было нельзя.** Во время загрузки модели
   `/models` отвечает 200, но чат отдаёт 502 ~20 минут. Health-check по `/models`
   пропускал вызов в заведомую стену.
3. **Deny-паттерн `curl .* | *(bash|sh)` глушил легальные команды.** Без границ слова
   ветвь `sh` матчила подстроку «sh» в любом слове (например `screenshot`), и VERIFY
   отвергал команду скриншота UI как «запрещённую».
4. **Повреждённый ручной `night_plan.yaml` (неэкранированное «: » в goal) валил всю ночь**
   на фазе PLAN вместо восстановления.

## Решение

1. **SSE-стриминг для локального провайдера** (`config.yaml`: `local.stream: true`;
   `providers._chat_stream`). Живой поток байтов gateway не режет по общему таймауту;
   idle-таймаут между чанками — `stream_idle_timeout_s: 180`. Если шлюз не умеет SSE
   (4xx на stream) — автоматический фолбэк на обычный POST (`kind == "stream"`).
   Проверено: генерация 7407 токенов за 181 c прошла без 502.
2. **Глубокий health-check = чат-проба на 1 токен**, а не `/models`. Плюс grace-период
   `night.local_load_grace_min: 25`: при недоступности local система ждёт загрузки
   модели и повторяет один раз; не ожила — честный halt в отчёт (не тихий ретрай-шторм).
3. **Deny-паттерны с границами:** `curl\s[^|]*\|\s*(ba)?sh\b` / `wget...` (соло-`sh`
   больше не матчится внутри слов). Позитивные тесты в прогоне: `run_screenshot.py`,
   `autonomy.screenshot` разрешены; `curl … | bash`, `taskkill` запрещены.
4. **Устойчивость плана:** битый YAML плана логируется и план перестраивается планировщиком,
   а не обрывает ночь. В промпт планировщика добавлено правило кавылировать скаляры с «: ».

## Альтернативы

- **Поднять `max_tokens` и молиться.** Не решило 502 (обрыв по времени соединения, не по лимиту).
- **Ретраи на 502.** Прям противоречит правилу «повтор добивает очередь» для локалки и
  маскировал бы реальную причину.
- **Гонять весь трафик облаком.** Платно и против приоритета бесплатных моделей; стриминг
  бесплатный и убирает корень проблемы.
- **Запрет «sh» целиком / чёрный список слов.** Хрупко; корректный путь — regex с `\b`.

## Последствия

- Локальный провайдер зависит от SSE; при смене версии Strata надо перепроверить фолбэк.
- Grace увеличивает худшее время одной итерации (до ~25 мин ожидания), но только когда модель
  реально грузится — взамен получаем честный сигнал вместо ложного провала.
- Анти-заглушка-сканер + строгий acceptance остаются единственной гарантией «измерено ≠ заявлено»;
  инфраструктурные фиксы её не ослабляют.
- Тест-корпус TTS→ASR (gTTS, edge-tts блокировался) даёт WER как ступень честности: это машинная
  речь, не живая; живой эталон с ручной разметкой всё ещё не собран (см. STATUS.md).

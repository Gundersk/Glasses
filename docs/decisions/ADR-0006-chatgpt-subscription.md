# ADR-0006 — существующий вход ChatGPT через OpenCode

- Дата: 13.11.2026; статус: принято по прямому запросу владельца.
- closes: LG-2026-11-13-02; область: оркестратор, не ASR-решение ADR-0002.

## Решение

Использовать уже подключённый `openai` в OpenCode 2.2.7, без повторного входа,
чтения OAuth-файлов или прямого запроса к приватному ChatGPT endpoint.
`openrouter/openai/...` — отдельный платный API-маршрут, не подписка Plus.
Заменены активный reviewer и платный резерв критика; резерв API GPT удалён.
Бэкапы/исторические логи намеренно не переписываются.

Kimi остаётся первым у mentor/critic. ChatGPT Sol high — сильный резерв;
Terra medium — автор/планировщик. Это назначение, **не измеренная калибровка**.
DeepSeek/Qwen — запас автора, GLM — короткие служебные роли;
assistant/researcher/explore не расходуют Plus по умолчанию. Автор и контроль —
разные модели; цена подписки 0 не означает независимость или безлимит.

Адаптер `autonomy/opencode_provider.py`: `opencode api`, свежая сессия и
`/generate` без цикла агента/инструментов. Вход передаётся чанками через durable
instruction entries, не длинным argv Windows. Внешние страницы — данные, не
разрешение менять правила. Проверяются пустой API-прайс каталога и жёсткий
потолок варианта (12k автор / 24k контроль, включая reasoning). Маркер окончания
не позволяет принять обрезанный текст за полный. Обрезанный подписочный ответ
не вызывает автоматического удвоения бюджета; платного GPT fallback нет.

## Контекст и квота

Встроенный `openai-context-caps` не отключён: каталог GPT-6.1 показывает input
500k/context 628k/output 128k; более старые — input 272k/context 400k/output 128k.
Это **метаданные**, не проверка предельного входа. Compaction: auto, summary
(переносим между моделями), keep 24k, buffer 20%; warming выключен, фоновая
компактизация не включена. Буфер считается от окна выбранной модели; миллион
из OpenRouter не задаём. Ночные вызовы свежие: только контракт/задача/нужные
входы; консервативный UTF-8-байтовый лимит блокирует избыток без обрезки.
Корневой default проекта тоже переопределён на подписочный OpenAI: глобальный
платный GPT больше не наследуется этим проектом. Дешёвый глобальный compaction
агент сохранён; потеря деталей summary компенсируется опорными файлами, не
обещанием безошибочной памяти. Смена этой политики снимает approval плана.

SQLite-журнал общий для моделей и изолированных заданий: до 10 резервирований
за запуск, 60 за скользящие 7 суток. Это начальная **локальная политика**, не
пересчёт Plus в запросы и не гарантированный запас. Ручные сессии и внутренние
retries OpenCode в счётчики не входят. После полуночи бюджет и попытки
незавершённого запуска больше не обнуляются. Подписочные preflight-пробы пропущены.

При quota: сначала допустимая независимая альтернатива, затем ожидание в том же
вызове. retryAfterMs + 60 с; неизвестный короткий сброс — 5 ч 5 мин + 60 с,
одна попытка после ожидания. Неизвестный недельный — остановка, общий cooldown
7 суток (консервативно), не считать пятичасовым. Известный сброс до 6 часов можно
дождаться независимо от типа окна. Локальные caps не обходятся. Сохраняются
STATE/heartbeat; окно исполнения продлевается на ожидание, не повторяются команды
всей фазы. STOP прерывает ожидание. Никаких триггеров/возобновления после перезагрузки:
процесс должен оставаться запущенным, ПК — не спать. Падение процесса сохраняет
fail-closed recovery: нельзя повторять незавершённую фазу с побочными эффектами.

## Альтернативы и ограничения

- Перенос OAuth в Python: отвергнут (секреты, refresh, нестабильный API).
- `opencode run` с инструментами: отвергнут (выход за sandbox, лишние шаги).
- API GPT fallback убран по запросу владельца; экономия ещё не измерена.
- Native compaction не выбрана: непрозрачный непереносимый checkpoint.
- `/api/experimental/usage/limits` описывает Go/Console, не ChatGPT. Не показывать
  фиктивный остаток Plus и не обещать сроки при исчерпанной неделе.
- Адаптер зависит от экспериментального API; неизвестная ошибка блокирует вызов,
  а не считается успехом. Классификацию реальной ошибки квоты нужно проверить.

Каталог/конфиг и CRUD сессии/инструкций проверены **без генерации**. Новый
подписочный ответ, настоящий 429/сброс не запускались. Оффлайн-тесты не заменяют
ограниченный живой smoke после отдельной команды. Источники S071–S073;
протокол: `docs/audits/2026-11-13/subscription-tests.json`.

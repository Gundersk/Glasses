# ADR-0012: доказуемое reuse и ограниченный резервный reader

15.11.2026. `closes: LG-2026-11-15-01`. Статус: реализовано с ограниченной live
проверкой Contents. Не изменяет карту, старые карточки, квоты поиска или verdicts.

## Решение

1. При выборе источников dedup по DOI/arXiv/осторожному длинному title-кандидату.
   Сильные ID, явные версии и supplements проверяются на конфликты; title не
   доказательство идентичности. Оригинальный URL/версия сохраняются.
2. Явное research_policy.reuse_sources разрешает receipt-bound архив последних
   30 дней. Non-mock approved research command rc0 + совпадающий output SHA,
   source/receipt paths и hashes, original_accessed/TTL проверяются повторно.
   Loose cache не источник archive reuse. Новая карточка записывает новый
   source artifact с исходной датой/lineage, не наследует научный PASS.
3. TinyFish остаётся web discovery; при известном отказе search и разрешённом
   reuse можно отобрать кандидаты локально. Это явно не свежий интернет-поиск.
   Для выбранных точных URL: проверенный archive → TinyFish → Valyu Contents
   только при явном subbudget/max_reader_calls и известной причине отказа.
   Ни нового URL, ни повторных запросов модели при переключении нет.
4. Valyu только normal extraction, summary=false, max_age0. Search/Answers/
   DeepResearch не включены. Каждый вызов резервирует$0.01 в persistent SQLite;
   scope-budget/callcap, общий20/day, single-flight/circuit/cooldown. Расход =
   сумма max(резерв попытки, известная стоимость). Отдельный worker имеет общий
   deadline и kill; это локальная остановка, не доказанная server cancellation.
5. Резерв reader вычитается из доступного model-budget заранее, начисляется
   дельта без двойного счёта. Ошибка/перерасход блокирует дальнейшую платную
   работу до оператора. Actual reported costs отдельно от reserve, отсутствие
   cost не бесплатно, несовместимые cost поля блокируют страницу/провайдера.
6. Журнал на каждый query `sources-N.md.retrieval.jsonl` пишет started/исход,
   provider, точные URL, причины переключения и reserve/cost. Частичный журнал
   сохраняется даже при сбое до итогового JSON. Финальный source JSON также
   содержит retrieval_log и происхождение. Старые receipts/logs неизменны.

## Почему не иные варианты

Смена модели поиска не решает проблему уже имеющейся открытой копии. Автопересказ
Perplexity не первичный текст. Универсальный DOI-resolver/OpenAlex и дополнительная
платформа пока не нужны. Exa не показал пригодный текст двух прошлых URL;
новый provider включается по тестируемому контракту/лимитам, не по обещанию доступа.

## Границы

Новые optional policy поля отсутствуют у legacy, авторасхода им не добавляют.
Ключ только VALYU_API_KEY в окружении (runtime-процесс smoke получил из локального
секретного файла без вывода; значение не копируется в проект/глобальный конфиг).
Для постоянной автономной работы владелец задаёт env до запуска; ключ в temp
не читается рабочим клиентом. Новый запрос на обзор всё ещё требует согласования.
Не гарантируем billed cap, полную публикацию, корректность выводов или новую
автономную научную приёмку. Паузы/блокировки/CAPTCHA не обходятся.

Valyu дваHTTP200. Exact reported invoice smoke неизвестен. Артефакты:

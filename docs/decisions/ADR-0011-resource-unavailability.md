# ADR-0011: недоступный URL не равен неисправности интеграции

14.11.2026. `closes: LG-2026-11-14-03`.
Статус: реализовано/проверено оффлайн, новый живой обзор не запускался.
Не меняет обязательства карты, прежние квоты и старые run.

## Причина

v6 остановился на второй поисковой команде: выбранные IEEE/ADS вернули
bot_blocked. Третий разрешённый запрос и резерв остались неиспользованными.
Общее fail-fast было полезно при сломанной интеграции, но слишком жёстко
для ожидаемой недоступности отдельных страниц.

## Решение

Новые policy-планы явно содержат --allow-unavailable. В этом режиме известные
ресурсные коды (bot_blocked/robots_denied/access_denied/not_found/403/404/410/gone)
и настоящий пустой поиск сохраняют schema-v2 outcome. `.md/.json` существуют,
но sources=[] и SOURCE UNAVAILABLE явно означают отсутствие доказательств.
rc0 означает корректно сохранённый исход команды, не успешное чтение страницы.

Typed `research_collection` проверяет все разрешённые query manifests, request ID,
URL/query/page caps, причины пропусков и реальные страницы. Если есть реальные
страницы — разрешается дальнейшая оценка достаточности/partial; если нет ни
одной или schema повреждена — ответ не создаётся. Проверка цитат/полного покрытия
и независимый смысловой REVIEW остаются обязательными.

Автор получает actual-page excerpts отдельно от unavailable_sources. Из пустого
manifest нельзя поддержать claim. Followup привязывает прежние source-файлы как
inputs и не повторяет уже принятый сбор. Лимиты запросов/страниц/попыток/часов
не увеличиваются; не добавляются reader-retries, новые URL или скрытый поиск.

Unknown/MCP/auth/rate/network/schema ошибки остаются fatal. Оба поля status и
status_code проверяются независимо. TinyFish возвращает только valid/requested
страницы; invalid_results не превращается в source. Legacy без opt-in сохраняет
прежний отказ, если страниц нет. Старые карточки/STATE/вердикты не мигрируются.

## Альтернативы

Безусловный стоп при любом URL-отказе — слишком хрупко. Безусловное продолжение
при любой ошибке — скрывает сбои интеграции/квоты; отвергнуто. Принимать модельный
пересказ как страницу или отключать цитатные проверки — отвергнуто.

Exa проверен отдельно: по брифу researcher IEEE дал оболочку, ADS timeout;
TinyFish повторно дал bot_blocked обоим. Улучшение на этих URL не показано.
Автоматический платный reader/Perplexity fallback не включён: нужна отдельная
калибровка и проверяемый учёт reader/query/token costs. Нативный поиск модели
не является доказательством чтения статьи. Поиск альтернативной открытой копии
возможен в пределах отдельного разрешённого запроса, с собственным URL/цитатой.

## Проверки и ограничения

304 unittest +23 standalone PASS, два ограниченных статических reviewer PASS
после исправлений. Сценарии: available/blocked/available -> проверенный mocked
partial; all unavailable -> blocked без автора; fatal second -> third не запущен.
Это не доказательство качества живой модели или автономной готовности проекта.
Причина защиты самих сайтов не установлена — имеются только provider codes.

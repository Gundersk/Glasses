# ADR-0001. Среда OpenCode и роли моделей

- **Дата:** 2026-11-06
- **Статус:** принято
- **Контекст:** проект УрФУ «Субтитры с определением говорящего для умных очков»; OpenCode v2.2.5; OpenRouter; Windows; AMD RX 7700 XT без CUDA.

## Решение

1. Использовать **проектную** конфигурацию `.opencode/opencode.json`, не менять глобальные настройки без необходимости.
2. Главный агент — `mentor` на `openai/gpt-6.1-terra#high` (баланс качества и цены). Эскалация — `openai/gpt-6.1-sol` для ревью и сложных решений.
3. Дешёвые субагенты:
   - `researcher` — `deepseek/deepseek-v4.1-flash-1017#high`;
   - `digester` — `z-ai/glm-5.3-flash#low`;
   - `vision` — `google/gemini-3.6-flash#high`.
4. Дорогие субагенты только по делу:
   - `reviewer` — `openai/gpt-6.1-sol#high`;
   - `implementer` — `anthropic/claude-sonnet-5.5#high`.
5. Поиск — встроенный `websearch` с провайдером **Exa**. Context7 подключён как MCP для документации библиотек. Tavily не добавляем по умолчанию: Exa уже работает, а второй поисковик увеличивает стоимость и сложность. Добавить Tavily можно позже, если Exa не хватает.
6. Каскад: `researcher` → при необходимости `digester` → `mentor`. Сырые страницы не попадают в контекст дорогой модели.
7. `subagent_depth: 1`: субагенты не запускают своих субагентов. Это защита от лавинообразного расхода токенов.
8. Авто-компакция с сохранением 20 тыс. токенов; `tool_output` ограничен 1200 строками / 48 КБ.

## Альтернативы

- **Одна дорогая модель на всё.** Проще, но дороже в разы; сырые результаты поиска быстро съедают контекст.
- **Только дешёвые модели.** Дёшево, но риск слабых архитектурных решений и ошибок в отчёте.
- **Tavily вместо Exa.** Не даёт преимущества на старте; Exa уже настроена.
- **Локальная LLM.** Не рассматривается: нет CUDA, 12 ГБ VRAM, приоритет — ASR-эксперименты, а не LLM.
- **Глобальная конфигурация OpenCode.** Проектная конфигурация безопаснее: не влияет на другие проекты.

## Последствия

- Нужны ключи: OpenRouter (есть), Exa (есть). Tavily/GitHub/Context7 API — опционально.
- Цены в `docs/model-policy.md` — ориентир; перед важным запуском проверять фактическую цену.
- Для аудио/видео нужен `ffmpeg`; для Python — `uv`.
- Качество моделей не проверено на наших задачах. Первый эксперимент должен сравнить хотя бы 2 модели ASR, а не выбирать по названию.

# Проверка двух недоступных URL v6

14.11.2026. `closes: LG-2026-11-14-03`. Это диагностика, не литературный обзор.
Старые v6, STATE и вердикты не изменялись. Нового поиска по теме не было.

## Что проверено

Из кэша поиска v6 восстановлен детерминированный выбор двух страниц:
IEEE9053900 и ADS2020spsi.conf..906R. Первая имела score9, вторая8;
кандидат arXiv с score8 остался за лимитом страниц. Это эвристический score,
не доказательство доступности/первичности или идентичности копий статьи.

| URL | TinyFish, новый прямой batch | Exa web_fetch_exa, по брифу researcher |
|---|---|---|
| https://ieeexplore.ieee.org/document/9053900 | 0 символов, bot_blocked | 1016 символов: заголовок/навигация/аккаунт, тела статьи и abstract нет |
| https://ui.adsabs.harvard.edu/abs/2020spsi.conf..906R/abstract | 0 символов, bot_blocked | CRAWL_LIVECRAWL_TIMEOUT, текста нет |

TinyFish: `source-access-tinyfish.json`, прямой Python-клиент проекта, один batch
двух URL с fresh=True. Не требовалась установка или регистрация нового MCP.
В UI subagent не нашёл TinyFish MCP tools — это не доказательство отсутствия
работающего проектного клиента. Рекомендацию researcher установить новый MCP
не исполняли. Код диагностики: `experiments/source_access_diagnostic/check_tinyfish.py`.

Exa: исследовательская сессия `ses_e2526009dffeIKA7U5HvJeZqO5`, по одному чтению
каждого URL, maxCharacters5000. Сырой ответ/снимок не сохранён из-за лимита шагов;
результат здесь по брифу, основная сессия его повторно не вызывала. Это ограничивает
воспроизводимость сравнения. Время/HTTP-код самого сайта неизвестны, Exa мог
использовать индекс/свой crawler. Полного текста по обеим страницам не получено.

## Чего нельзя заключить

bot_blocked и timeout — классификации провайдеров. Не установлены точные
HTTP-ответы сайтов, правило firewall, IP-репутация, robots-policy или механизм
защиты. Проверка не доказывает, что сайт вообще недоступен человеку или другому
читателю. Но преимущество Exa на этих двух URL не показано. Оболочка страницы
не становится статьёй только потому, что инструмент вернул непустой текст.

## Альтернативы и стоимость: источники, не наши измерения

По брифу researcher (четыре официальные страницы, 14.11):
- https://exa.ai/pricing — Contents заявлен $1/1000 страниц; реальный счёт данной
  MCP-проверки и применённый тариф неизвестны, billing cap этим не подтверждён.
- https://exa.ai/products/contents — назначение Contents как reader, не генератор обзора.
- https://openrouter.ai/docs/guides/features/plugins/web-search — web search может
  использовать Exa; native поиск Perplexity и url_citation не гарантируют полный
  первичный текст. Поиск может иметь дополнительную стоимость.
- https://openrouter.ai/docs/guides/features/server-tools/web-search — ограничения
  max_results; точная цена конкретной Perplexity-модели/поиска здесь не установлена.
Версии страниц и лицензии документации не зафиксированы; сырьё не сохранено.
Поисковые Perplexity/OpenRouter inference-вызовы в этой проверке не выполнялись.

## Решение

Автоматический платный fallback не включать без показанного выигрыша, цены,
cap числа reader-попыток и подтверждённого локального учёта. Поисковую модель
можно отдельно испытать как генератор кандидатов URL; её ответ не сохранять
как прочитанную статью. Для копии на arXiv/авторском сайте нужны собственный URL,
чтение и проверка соответствия; не подменять IEEE URL текстом другой страницы.

Исправление сейчас: недоступность конкретных выбранных URL записывается typed
manifest; остальные уже разрешённые запросы продолжаются. Никаких скрытых
новых запросов/URL/ретраев или CAPTCHA. При отсутствии всех реальных страниц —
blocked; при неисправности MCP/auth/rate/schema — прежняя остановка.

# Chat2API: ограниченный исследовательский бриф

`closes: LG-2026-11-14-01`. Дата 14.11.2026.
Исследователь остановился по лимиту шагов; его файл не был создан.
Этот бриф фиксирует полученный ответ, не завершённую проверку локального сервиса.

1. Локально прочитаны только имена/метаданные провайдера `chat2api` из
   `~/.config/opencode/opencode.jsonc`. Package — OpenAI-compatible;
   endpoint — loopback `/v1`. Значения ключей не копировались в проект/логи.
2. Имена моделей и context/output — декларация владельца конфигурации.
   Нативный поиск, function calling, окно, качество и реальные дневные квоты
   не подтверждены самим конфигом. Tool calling в первом маршруте отключён.
3. По брифу researcher: https://github.com/lanqian528/chat2api — кандидат MIT,
   ChatGPT Web → OpenAI-compatible. Он не доказывает мультипровайдерный backend.
   Версия/лицензия именно локальной установки неизвестны; код не заимствуется.
4. https://github.com/xiaoY233/Chat2API — второй кандидат по совпадению семейств
   моделей; принадлежность локального gateway и лицензия не установлены.
   Нельзя выдавать совпадение имён за проверенную идентичность upstream.
5. По брифу researcher: https://opencode.ai/docs/providers и
   https://opencode.ai/docs/config описывают `providers`, `package`,
   `settings.baseURL`, `models` и проектные overrides. Дата 14.11.2026, V2;
   лицензия документации отдельно не проверена. Глобальный конфиг не меняем.
6. Пауза/circuit breaker — локальные предохранители, а не гарантия отсутствия
   блокировки или разрешения автоматизации условиями площадки. CAPTCHA/auth
   требуют ручного вмешательства; не решаем их и не меняем аккаунты в обход.
7. Рекомендация: только digest/scout с отдельным малым контекстом и проверяемой
   маркировкой. Scout возвращает кандидаты, не принятые первичные источники.
   Critic/verifier, карточки с фиксированными поисковыми квотами и штатный
   поиск не заменяются до отдельной калибровки/согласования.

Осталось проверить: upstream/version/условия сервиса; ограниченный live smoke;
достоверность URL/цитат и наличие реального поиска; качество на фиксированных
примерах. Модельный ответ сам по себе не доказывает, что поиск выполнялся.

## Что реализовано для первого задания

Карточка → привязка к scope/контексту → отдельный план/STATE/цели → критик →
детерминированный сбор источников с receipt → три файла ответа без команд →
проверка URL/цитат/решения → независимый сильный REVIEW → отчёт/digest.

Проверяется отказ при правке контекста/карточки, ложной цитате, обходе зависимостей,
перезаписи источников исполнителем, необходимости измерений и автоматическом
replan. Интеграционный тест проходит фазы с временными страницами/ответами без сети;
он не вызывает рабочий tick. Итоговые команды, логи и хэши — `offline-tests.json`.

**Готовность:** можно согласовать вход первого документного задания. Живой допуск
отдельный; качество исследования/оптимальность моделей и снижение участия
владельца ещё не измерены. Даже честная цитата может поддерживать неверный вывод,
а шесть страниц поиска не гарантируют полноты рынка/литературы.

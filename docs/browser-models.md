# Браузерные модели: вспомогательный маршрут

`closes: LG-2026-11-14-01`. 14.11.2026. Решение: ADR-0009.

**Статус:** код интегрирован, 235 unittest + 23 отдельные проверки PASS;
ограниченное статическое ревью PASS после исправлений. Живой маршрут ещё
не принят: два обращения за сжатием blocked, принятое сжатие не получено.
Сводка и условия: `experiments/browser_gateway_smoke/README.md`.

## Что известно и что пока нет

**Локальная конфигурация:** глобальный `opencode.jsonc` содержит `chat2api`,
OpenAI-compatible package, loopback `http://127.0.0.1:8080/v1` и семь ID.
Глобальный файл/ключи не менялись и не копировались. Клиент использует
`CHAT2API_KEY` и опционально `CHAT2API_BASE_URL` из окружения, не извлекает
браузерные cookies/учётные данные. Round Robin внутри сервиса не меняем.

**Получено технической проверкой:** GET `/v1/models` вернул HTTP 200 и 23 ID
(`docs/audits/2026-11-14/chat2api-catalog.json`). Глобальные алиасы отличаются
от ID сервера. Наш YAML явно сопоставляет deepseek-flash → deepseek-v4-flash,
deepseek-pro-think → deepseek-v4-pro-think, qwen-max → Qwen3.7-Max,
qwen-coder → Qwen3-Coder, kimi → Kimi-K2.6, perplexity → Auto;
GLM-5.1 совпадает. Auto не доказывает конкретную модель/поиск Perplexity.
В каталоге также есть PPLX-Pro, GPT-5, Gemini-2.5-Pro, Claude Sonnet/Opus 4,
Nemotron и search/think-варианты DeepSeek. Они **не включены автоматически**:
наличие имени не подтверждает права/квоту/работу или независимость критика.

| ID | Декларировано context/output, токены | Кандидат на роль (гипотеза) | Наш cap попыток/UTC-день |
|---|---|---|---|
| deepseek-flash | 32000 / 8000 | короткое сжатие, default digest | 12 |
| deepseek-pro-think | 32000 / 12000 | трудный анализ уже данных материалов | 4 |
| GLM-5.1 | 32000 / 12000 | дополнительный анализ, не финальное ревью | 4 |
| qwen-max | 32000 / 8000 | структурирование русскоязычного текста | 8 |
| qwen-coder | 32000 / 8000 | пояснение фрагмента кода; не автономное исполнение | 4 |
| kimi | 64000 / 8000 | сжатие более длинного источника, после калибровки | 6 |
| perplexity | 16000 / 4000 | кандидаты источников, default scout | 6 |

Это **не измеренные окна/качество**, не доказанная идентичность backend,
не проверенная поддержка tools или поиска. Дневные лимиты, заданные в панели
сервиса, не видны в глобальном JSON: их не синхронизировали и не увеличивали.
Наши caps — дополнительные консервативные ограничения. Сервис может отказать раньше.
Совокупно максимум 30 попыток в UTC-день, включая неудачные. Другие приложения
и прямые вызовы через OpenCode наш ledger не учитывает.
Считаются HTTP-обращения нашего клиента к шлюзу, не скрытые upstream-попытки:
внутренние retries/смену аккаунтов самим сервисом мы пока не проверяли и не
контролируем. Для строгого контроля их нужно отдельно проверить/отключить в
панели сервиса; локальный cooldown не доказывает отсутствие внутренних повторов.

## Применение

Команды OpenCode: `/cheap-digest <документ/задача>`, `/source-scout <вопрос>`.
В Python-маршрутизаторе добавлены только роли context_digest/source_scout.
Planner/executor/critic/verifier и штатный поиск не переназначены.
Не вызывайте дополнительного digester для того же простого сжатия.

```powershell
# Только dry-run, модели не вызывает:
.venv\Scripts\python.exe -m autonomy.assist digest --input docs/browser-models.md
# Один явно разрешённый вызов; fallback к существующим API, до $0.05 локальной оценки:
.venv\Scripts\python.exe -m autonomy.assist digest --input docs/browser-models.md --execute --wait-seconds 60
# Только шлюз, без платного fallback; разрешён любой ID из таблицы:
.venv\Scripts\python.exe -m autonomy.assist digest --text "Короткий неперсональный фрагмент" --model qwen-max --browser-only --execute
.venv\Scripts\python.exe -m autonomy.assist scout --text "Первичные работы по русскому потоковому ASR" --browser-only --execute
# Без сети:
.venv\Scripts\python.exe -m autonomy.assist status
```

Локальный бюджет fallback относится к **одному вызову**, не ко всем будущим
командам и не к абсолютному billing cap. Fallback — deepseek1017 → qwen38_flash
в пределах существующей проверки бюджета; платного OpenAI fallback нет.
Ответ помечен unverified_auxiliary. Исходные документы и STATE не изменяются.
Просмотр результата не означает его приёмку в отчёт.

## Контекст и доказательства

Отправляется короткий системный контракт и явно выбранный текст, не вся история,
AGENTS/секреты/сырые логи. CLI: максимум 10000 символов входа; клиент имеет
отдельные ограничения по модели. Нет молчаливого обрезания/автоматического
многочастного цикла. Для большого файла сначала выберите нужный фрагмент.
Входные пути разрешены только из docs/reports/experiments; это не DLP: перед
отправкой необходимо исключить персональные данные, ключи и приватные материалы.

Нативный поиск нельзя считать гарантированным/безлимитным: исходящий chat-запрос
не доказывает вызова поиска. URL и цитаты проверяются обычным чтением страницы;
ответ scout сам по себе не источник и не доказательство. Fallback к обычному
API может лишь предложить запросы, не иметь браузерного поиска.
Не использовать scout внутри карточек research_policy: его скрытые внутренние
запросы сейчас не входят в согласованный счётчик. Это отдельная вспомогательная
команда, не замена research.research/receipt и не автоматическое расширение карты.

## Паузы и ограничения аккаунтов

- Single-flight на весь gateway и общий cooldown не менее 60 секунд; смена модели
  не снимает ограничение. Короткую обычную паузу можно явно ждать до 60 секунд.
- 429: общий cooldown минимум 15 минут, по Retry-After, по умолчанию час.
- CAPTCHA/auth/challenge и неизвестное завершение запроса требуют ручной проверки;
  не решаем CAPTCHA, не перелогиниваемся и не переключаем аккаунты для обхода.
- Паузы не гарантируют отсутствие бана и не заменяют условия площадок.
- Недоступность шлюза допускает только разрешённый API fallback, а не ослабление
  критика. Если всё недоступно — blocked. Повторов генерации внутри клиента нет.
- Клиентский timeout не доказывает остановку серверной генерации. Зависший owner
  не перехватывается автоматически. После реальной ручной проверки/остановки
  операции: `python -m autonomy.assist clear-hold --execute`; counts/cooldown
  сохраняются, действующая lease не очищается. Не делать это автоматически.

Точный upstream/версия/лицензия локального gateway не установлены;
`docs/audits/2026-11-14/chat2api-research.md` фиксирует частичный бриф.
Нельзя гарантировать снижение квоты или качество до сравнительной калибровки.

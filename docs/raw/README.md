# docs/raw — сырые материалы

Сюда `researcher` может сохранять большие сырые выдержки, чтобы не тащить их в основной контекст.

Правила:
- имя файла: `YYYY-MM-DD-краткий-слаг.md`;
- в начале файла — URL, дата обращения, версия/лицензия;
- это черновик, а не отчёт; в `docs/sources.md` попадает только итоговая ссылка;
- содержимое не коммитится (см. `.gitignore`), потому что может быть большим и/или чужим.

Дальше `digester` читает файл и сжимает до ≤400 слов, а `mentor` получает только бриф.

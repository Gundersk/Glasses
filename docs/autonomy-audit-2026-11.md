# Аудит автономного сопровождения — 12.11.2026

closes: `LG-2026-11-12-01`.

## Итог и граница допуска

Сохранён существующий Python-оркестратор, устранены приоритетные обходы критика,
приёмки и бюджета; добавлены протоколы исполнения. **Это проверка программного
кода, не доказательство готовности бесконтрольной ночи.** Новые ASR/DER/задержки
не измерялись. Ночной tick, preflight, супервизор и новые живые вызовы автономных
моделей в аудите не запускались. Argus остаётся закрытым пилотом.

Подтверждённый результат: 66 unittest и 23 отдельных оффлайн-проверки проходят;
одна из unittest запускает короткий синтетический subprocess во временном каталоге.
Ни этот subprocess, ни mock не являются научным экспериментом.

приёмка. Новая идея должна проходить гипотезу → критика → LG/RC → бюджет → опыт.

## Что остаётся риском

1. Прикладные пути/паттерны не являются OS sandbox. Процесс с правами владельца
   может менять доказательства и выполнять опасный код; receipt не подписан извне.
2. Произвольное восстановление и exactly-once побочных эффектов не реализованы.
   Новый tick при незавершённой задаче требует человека, а не возобновляет её сам.
3. Хэшируются только объявленные файлы. Полный граф входов (WAV, веса, импорты,
   параметры окружения) не раскрывается автоматически. Текущий двухзадачный
   night_plan — заготовка, не готовый одобренный smoke: проверить входы и явно
   объявить все результаты, включая читаемые командами acceptance.
4. Freshness по хэшу/mtime выявляет старый нетронутый файл, но touch/перезапись
   сами по себе не доказывают новое вычисление. Методика и научные выводы — отдельно.
5. Локальный бюджет не гарантирует абсолютный биллинг при сетевом обрыве или
   неизвестной цене; нужен provider-side cap. Лимит качества критика не калиброван.
6. Redaction известных секретов — best effort. Внешние страницы/README/issues —
   недоверенные данные, не инструкции. Логи проверять перед внешней передачей.
7. Корпуса: S058 подтверждает существование русского синтетического RTTM-набора,
   не качество на естественном диалоге; права исходников отдельно не проверены.
   S059 raw fetch дал 401. Тезисы «русских данных нет»/«аналогов нет» не доказаны.

## Следующий допуск — только после отдельной команды владельца

- Сначала решить, разрешены ли несколько живых вызовов для калибровки критика
  на фиксированных корректных/ошибочных случаях; учесть поиск, отказы, цену и квоту.
- Для одного smoke: сохранить прежний STATE/артефакты без уничтожения; свежий PLAN,
  не-mock, одна заранее проверенная задача, один запуск, конечный бюджет, без
  супервизора, восстановления и auto-replan. Проверить все команды и результаты.
- Проверить receipt, логи, версии, входы и расчёт метрик вручную; неисправленная
  high-ошибка/сбой критика/неполный протокол → остановка, не «успех с оговоркой».
- Дальше — обязательные T2, запись/видео, диаризация и отчёт к 25.11. Аудит
  не закрывает пункты карты и не разрешает бесконечно улучшать оркестрацию.

# Поиск и чтение: что включено и как проверять

15.11.2026. `closes: LG-2026-11-15-01`, ADR-0012.

## Маршруты

- Discovery: TinyFish. При известной недоступности сервиса и разрешённом reuse —
  локальные кандидаты из receipt-bound архива, с пометкой «не свежий web search».
- Выбор: одна предпочтительная копия в пределах совместимых bibliographic-ID/
  title-групп. Разные явные версии, supplement и конфликтующие DOI не объявляются
  одним текстом. Предпочтение сохранённой копии/HTML — эвристика, не гарантия.
- Чтение выбранного exact URL: archive, если явно разрешено и проверены receipt,
  SHA/TTL; затем TinyFish; затем Valyu Contents, только с заранее выделенным
  бюджетом и подтверждённым отказом конкретного URL либо всего сервиса.
- Неизвестная schema/JSON-ошибка не разрешает платный fallback. Auth/rate/timeout
  могут позволить отдельно разрешённый reader, но не снятие ограничения исходного
  аккаунта. Неуспешный fallback whole-service оставляет исход fatal.
- Все конкретные страницы недоступны: typed unavailable/blocked по ADR-0011;
  найденные snippets/пересказы не превращаются в первичный текст.

Автоматической альтернативной поисковой модели/API Valyu Search сейчас нет.
Новый web search по другому провайдеру — тоже расход и требует отдельного cap;
не прячем его за старым счётчиком одного запроса. OpenAlex/DOI-resolver не внедрён.

## Новая карточка (пример только фрагмента policy)

```json
{
  "reuse_sources": true,
  "retrieval_budget_usd": 0.02,
  "max_reader_calls": 2
}
```

Эти поля дополняют topics/остальные обязательные policy limits. Reader subbudget
не больше budget_usd карточки; он заранее резервируется из общего model-budget.
0.02USD и2попытки — локальная консервативная оценка, не гарантированный billing cap.
Все actual/unknown попытки считаются, возврата резерва при ошибке нет.
Пустые поля/старые карточки не получают расходов и межзапускового reuse автоматически.
После регистрации карточку/контекст не редактировать; использованный ID не повторять.

## Ключ и запуск

Рабочий клиент читает **только VALYU_API_KEY из окружения**, не temp/ValyuAPI.txt.
Перед автономным запуском владелец должен предоставить переменную в окружении
OpenCode/дочерних процессов безопасным способом. Не печатать значение и не коммитить.
Тестовый ключ уже проверен двумя Contents-вызовами; в постоянный env его не записывали.
Отсутствие env логируется missing_key; платных вызовов не происходит, страницы
остаются unavailable по прежней проверяемой логике. Новый аккаунт ChatGPT не
сбрасывает локальные quota/circuit и не доказывает обновлённые лимиты подписки.

Для отдельной технической диагностики:
`python experiments/valyu_smoke/check.py` — dry-run без сети.
`--execute` — отдельное явное разрешение на максимум2вызова; не запускать автоматически.
Сам скрипт не читает секретный файл. Новый обзор/ночь этим не запускаются.

## Журналы и provenance

`sources-N.md.retrieval.jsonl` — append-only клиентский журнал попыток, в том
числе начатых/незавершённых. Содержит provider, operation, outcome, URL, безопасный
error_code, reserve/cost/attempt_id. Нет headers/keys/raw errors.
URL берутся из публичной выдачи; не использовать секретосодержащие URL/токены
во входе. Valyu дополнительно отклоняет query-параметры и credential-like paths.
Журнал не подписан криптографически; итоговый JSON связан receipt, его provenance
содержит архивные хеши и адреса, exact URL не подменяется URL другой копии.

`autonomy/workspace/valyu.sqlite3` — общий между карточками ledger, исключён из git.
Счётчик не обнуляется при перезапуске/смене аккаунта ChatGPT. Не удалять ledger
ради продолжения; неизвестный in-flight/circuit требует операторской проверки.
Факты отчёта: reader counts/reserved/reported/unknown и общий charge. Резерв —
не actual bill. При конфликте/ошибке учёта paid_work_blocked останавливает работу.

Архив сохраняет original_accessed: новый artifact не делает старую публикацию
свежепрочитанной. Не переиспользуются loose caches без matching receipt; старый
scientific PASS не переносится, все claims заново проходят проверки и REVIEW.

## Проверки и оставшиеся границы

Протокол: `docs/audits/2026-11-15/retrieval-tests.json` —374 unittest,
373PASS/1skip (symlink privileges Windows), плюс23standalone. Ограниченные ревью PASS.
Live: arXiv HTTP200/30000символов, IEEEHTTP200/4895символов; полнота/семантика
статьи не проверены. Raw cost values не сохранены в smoke старой версии parser,
общий резерв0.02USD; новый parser поддерживает observed total_cost_dollars.
Ключ/отчётные tokens не являются научными результатами. Новый обзор не выполнялся.

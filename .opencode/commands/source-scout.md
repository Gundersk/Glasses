Вопрос пользователя: $ARGUMENTS

Проверь closes действующей задачи и `docs/browser-models.md`.
Если задача принадлежит неизменяемой карточке с фиксированным research_policy,
НЕ запускай этот маршрут: скрытые поиски не включены в её счётчик запросов.
Для отдельно разрешённого вопроса используй `python -m autonomy.assist scout`
с безопасно переданным коротким --text, --execute --wait-seconds 60.
Доступный fallback — существующий API, до $0.05 за этот вспомогательный вызов;
при запрете платы — --browser-only. Один вызов, без повторов/ночи.
Не утверждай, что native search состоялся: это требует отдельного доказательства.
Ссылки и цитаты — только кандидаты. Прочитай нужные страницы обычным маршрутом
researcher/поиска; не записывай модельный ответ как принятый первоисточник.
Сохрани различие: источник / план / измерено. При сбое честно сообщи blocked.

# Аудит лицензий

## Когда применять

Перед использованием библиотеки, модели, весов, датасета или SDK в проекте/отчёте/демо.

## Что проверять отдельно

1. **Код** — файл LICENSE в репозитории.
2. **Веса** — карточка модели, условия Hugging Face, отдельная лицензия.
3. **Датасет** — условия загрузки, согласие, персональные данные.
4. **SDK** — условия производителя, ограничения по моделям/странам.
5. **Зависимости** — лицензии транзитивных пакетов, если важно для распространения.

## Типы ограничений

- MIT / BSD / Apache-2.0 — обычно разрешительные; сохранять уведомления.
- CC BY 4.0 — атрибуция.
- CC BY-NC — некоммерческое использование; проверить, подходит ли проект.
- GPL/AGPL — распространение/сетевой сервис; юридический риск.
- «Research only» / gated — может запрещать коммерческое использование.
- Отдельные условия весов и кода могут различаться.

## Формат

```
| Компонент | Что | Версия | Лицензия | Ограничения | Дата проверки |
|---|---|---|---|---|---|
```

## Правила

- Не писать «open source» без названия лицензии.
- Не считать лицензию кода лицензией весов.
- Фиксировать дату проверки: лицензии меняются.
- Если не уверен — писать «не проверено» и не использовать в демо без решения.

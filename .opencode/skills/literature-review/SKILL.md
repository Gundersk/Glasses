# Обзор литературы и источников

## Когда применять

Нужно найти новейшую информацию, документацию, статьи, бенчмарки, лицензии или сравнить подходы.

## Порядок

1. **Вопрос.** Сформулируй 1 главный вопрос и 2–5 подвопросов. Запиши их в ответе.
2. **Стратегия поиска.**
   - Общие источники: `websearch` (Exa).
   - Документация библиотек: Context7 MCP.
   - Статьи: arXiv/DOI, Google Scholar, Semantic Scholar.
   - Код и релизы: GitHub releases/issues.
   - Лицензии: файл LICENSE, карточка модели/датасета, условия Hugging Face.
3. **Отбор.** Приоритет: официальная документация → рецензируемая статья → официальный репозиторий → качественный обзор. SEO-статьи и пересказы — только как подсказка, не как доказательство.
4. **Извлечение.** Для каждого источника: URL, дата, версия/коммит, лицензия, что именно подтверждает, ограничения.
5. **Синтез.** Сравни источники. Если расходятся — покажи расхождение, не выбирай удобный.
6. **Запись.** Внеси источники в `docs/sources.md`. Если источник важный, добавь ID (`S001`) в отчёт.

## Формат результата

```
## Вопрос
## Краткий ответ (3–7 пунктов)
## Доказательства (таблица)
## Числа и условия
## Неопределённости
## Ссылки (URL + дата обращения)
```

## Запрещено

- Ссылаться на источник, который не открывался.
- Писать «исследования показывают» без ссылки.
- Переносить чужие числа как свои.
- Игнорировать лицензию весов и датасета.
- Делать архитектурный вывод за ментора.

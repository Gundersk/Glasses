## 1. Что это

Проект «Система субтитров с определением говорящего для умных очков» в рамках программы выявления и поддержки талантливых первокурсников УрФУ (набор 2026/2027). Институт ИРИТ-РТФ, область наук — информационные технологии, тематика — ИИ и устройства для персонализированной медицины и сохранения здоровья.

Ментор — Летавин Денис Александрович. Дорожная карта v2 утверждена: согласование ментора 20.10.2026, председателя 22.10.2026. Официальные сроки: 10.10.2026–30.06.2027.

## 2. Конечная цель

Человек с нарушением слуха видит в умных очках субтитры речи выбранного собеседника с небольшой задержкой.

Исходная идея включала:
- выбор собеседника взглядом;
- голосовые профили;
- определение направления звука;
- уведомления о значимых звуках.

Это **не** обязательный объём до января. Обязательный объём — ниже.

## 3. Обязательный результат до января

1. Потоковое распознавание русской речи (ASR) без обязательного распознавания говорящего в потоке.
2. Опыт с диаризацией 2–3 говорящих на записях: метки, фильтрация реплик.
3. Таблицы точности (WER) и скорости/задержки.
4. Аналитический отчёт.
5. Демонстрация.

ASD (Active Speaker Detection) — предварительная проверка модели; успешный запуск не обязателен по утверждённой карте.

## 4. Что позже

- Связывание лица с голосом.
- Временные голосовые профили при выходе человека из кадра.
- Клиент на телефоне и/или эмуляторе очков.
- Сравнение on-device / cloud / edge / hybrid.
- Полноценные очки, gaze tracking, направление звука, уведомления о звуках, обучение большой модели с нуля — **не гарантированы** без отдельного согласования.

## 5. Логика системы

1. ASR распознаёт, **что сказано**.
2. Диаризация / голосовые embeddings группируют, **кому принадлежат фрагменты** (условные ID). Это не идентификация человека.
3. ASD + отслеживание лиц помогают определить, **кто из видимых людей говорит**.
4. Аудиовизуальная интеграция сопоставляет условную аудиометку с лицом. При выходе человека из кадра возможна попытка сохранить временный голосовой ID, но не уверенная физическая локализация.
5. Пользователь выбирает аудиометку (ранний MVP), затем видимое лицо нажатием, в будущем — взглядом при наличии датчиков.
6. Нужно состояние «неизвестный говорящий / низкая уверенность». Ошибочная атрибуция хуже честной неопределённости.
7. При одновременной речи диаризация не гарантирует выделение отдельных голосов — это отдельная задача target speaker extraction / speech separation.
8. Фильтрация одного говорящего может убирать важный контекст. Проверять режимы «все реплики», «с метками», «только выбранный».

## 6. Архитектура (кандидаты, не утверждённый стек)

| Инструмент | Назначение | Ограничения |
|---|---|---|
| sherpa-onnx | Локальное и потоковое ASR, мобильные платформы | Apache-2.0 для движка; лицензии весов проверять отдельно |
| WhisperLiveKit | Готовый локальный потоковый сервер ASR, WebSocket, опциональная диаризация | Apache-2.0; скорость и качество на русском проверять |
| faster-whisper | Оптимизированное распознавание Whisper | MIT; CPU int8, реальное время не гарантировано |
| whisper.cpp | Эффективный локальный Whisper | MIT; перспективен для on-device |
| WhisperX | Выравнивание по словам и диаризация записей | BSD-2-Clause; не низколатентная система живого диалога |
| pyannote.audio / Community-1 | Диаризация | Библиотека MIT; веса CC BY 4.0, нужен доступ Hugging Face |
| Light-ASD / LR-ASD | Активный говорящий по аудио и видео | Исследовательские реализации; ASD ≠ voice-ID ≠ направление |
| MediaPipe | Лица и видеопризнаки | Apache-2.0; не готовая связь лица и голоса |
| SpeechBrain ECAPA-TDNN | Голосовые embeddings | Проверять конкретные веса и условия |

Выделять **ядро обработки** и **адаптер вывода**. Пакет события: timestamp, текст, частичный/финальный статус, speaker ID, confidence. Это позволит вывести на браузер/телефон или драйвер очков.

Совместимость с очками:
- Brilliant Labs Frame/Halo SDK — BSD-3-Clause; Halo Emulator позволяет тестировать интерфейс без физических очков.
- Vuzix Z100 — SDK и условия уточнить.
- MentraOS — открытая платформа; лицензия на 25.10.2026 — Apache-2.0 (проверять).
- XREAL SDK, Even Hub — ограничения по моделям и условия производителя.

Эмулятор проверяет интерфейс, но **не** доказывает реальные задержки, автономность, доступность камеры, читаемость дисплея или gaze tracking.

## 7. Данные и метрики

- AVA ActiveSpeaker — обучение/проверка ASD; условия оригинальных видео проверять.
- VoxConverse — аудиовизуальная диаризация и RTTM.
- VoxCeleb — голосовые записи, условия проверять.
- Естественные тестовые диалоги 2–3 говорящих: подобрать разрешённые записи либо записать добровольцев с согласием; подготовить эталон. Собственная запись не единственный путь по PDF.
- Qwen3-TTS — синтетические диалоги; синтетика не доказывает качество на реальной речи.

Метрики:
- **WER** — доля ошибок слов.
- **DER** — временная ошибка диаризации.
- Ошибки атрибуции реплик, включая неизвестных/перекрывающихся говорящих.
- Время до первого читаемого и до окончательного текста: медиана, p95, влияние шума.
- CPU/GPU/RAM, энергия, пропускная способность, цена активного часа и нескольких потоков.
- UX: все реплики / метки / выбранный голос. Небольшой пилот не доказывает пользу для широкой популяции.

## 8. Риски

1. Первоначальный риск отсутствия замеров частично снят; текущие измерения и их ограничения — в `STATUS.md`.
2. Нет GPU с CUDA; локальные модели могут быть медленными.
3. Нет размеченных русских диалогов 2–3 говорящих.
4. Диаризация на перекрывающейся речи ограничена.
5. ASD не равна voice-ID и направлению звука.
6. Лицензии весов и датасетов могут быть некоммерческими.
7. Можно переоценить зрелость очков и gaze tracking.
8. Регулярные консультации с ментором не подтверждены.

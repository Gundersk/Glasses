# Данные

## Правила

- Персональные данные и записи голоса — только с согласия участников.
- Не коммитить аудио, видео, датасеты и веса моделей в git.
- Для каждого набора данных фиксировать: источник, лицензию, дату, число говорящих, язык, длительность.
- Синтетические данные (TTS) маркировать отдельно; не смешивать с реальными в выводах.
- Эталонная разметка должна быть проверена вручную; LLM-разметка — только черновик.

## Структура (предложение)

```
data/
  raw/          # исходники, не менять
  interim/      # промежуточные
  processed/    # готово к экспериментам
  reference/    # эталонные транскрипты/RTTM
```

Большие файлы хранить вне git (внешний диск/облако), в репозитории — только манифест и ссылки.

# OpenCodeGlasses — рабочая среда проекта

Проект: «Система субтитров с определением говорящего для умных очков» (УрФУ, ИРИТ-РТФ, 2026/2027).

## Что уже настроено

- **OpenCode v2.2.5**, проектная конфигурация `.opencode/opencode.json`.
- **По умолчанию — `assistant`** на DeepSeek V4.1 Flash: дешёвый чат для вопросов, статуса и навигации.
- **Старший ментор — `mentor`** на GPT-6.1 Terra: сложные задачи, архитектура, код, проверка. Переключение — `/mentor`, назад — `/assistant`.
- **Субагенты:**
  - `researcher` — поиск и проверка источников (DeepSeek V4.1 Flash);
  - `digester` — сжатие длинных текстов (GLM 5.3 Flash);
  - `reviewer` — критическая проверка (GPT-6.1 Sol);
  - `implementer` — код и эксперименты (Claude Sonnet 5.5);
  - `vision` — изображения/видео/ASD (Gemini 3.6 Flash).
- **Поиск:** Exa через встроенный `websearch`.
- **MCP:** Context7 (документация библиотек).
- **Авто-компакция**, лимиты вывода инструментов, `subagent_depth: 1`.
- **Документы проекта:** `AGENTS.md`, `PROJECT.md`, `ROADMAP.md`, `STATUS.md`, `docs/`.
- **Шаблоны:** `experiments/`, `reports/`, `data/`.

## Как пользоваться

В OpenCode:

- `/status` — обновить и показать состояние проекта.
- `/research <вопрос>` — запустить исследователя и получить бриф со ссылками.
- `/experiment <название>` — спланировать эксперимент по шаблону.
- `/report <месяц>` — собрать месячный отчёт.
- `/review <файл или тема>` — критическая проверка.
- `/vision <файл>` — анализ изображения/кадров/видео.
- `/mentor <задача>` — переключиться на старшего ментора.
- `/assistant` — вернуться в дешёвый режим.
- `/roadmap-change <идея>` — предложить изменение дорожной карты.

### Как работать

1. Обычно сиди в `assistant`: задавай вопросы, проси напомнить статус, искать факты.
2. Если задача сложная — напиши `/mentor` или попроси ассистента «вызови ментора».
3. После работы — `/status`, чтобы зафиксировать, где остановились.
4. Вручную менять модель через `/models` нужно только для конкретной модели; для обычной работы не требуется.
